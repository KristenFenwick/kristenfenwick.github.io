Models · 03

Standardize the features

before distance-based models (SVM, k-NN, …)

The problem

Features live on different scales. Income might be 0–200,000; age 18–90; a binary flag 0/1. Models that care about distance or magnitude of weights will obsess over the big-number features and ignore the rest.

What StandardScaler does

z = (x − mean) / std

Each feature ends up roughly mean 0, variance 1 (on the training set).

Fit on train only. Then transform train and test. Fitting on all data leaks test information.

Do scale for

  • SVM (especially RBF)
  • k-NN, k-means
  • PCA
  • Regularized linear models (often)
  • Neural nets (usually)

Often skip / different for

  • Tree models (RF, XGBoost) — splits don’t need scaling
  • Already comparable counts in one unit
  • Sparse binary bags of words (sometimes different norms)

sklearn pattern

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)

Honest note

Scaling won’t fix a bad target, leakage, or a toy dataset that scores 100% forever. It’s hygiene — necessary, not magical.
