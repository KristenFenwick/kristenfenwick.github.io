Support Vector Machine

in natural language

What is SVM?

A supervised algorithm for classification (and regression). It finds the best separating boundary — a hyperplane — so that points from different classes sit as far apart as possible from that boundary.

How it works

  1. You have labeled points (class A vs class B).
  2. SVM searches for a line (2D) or plane (higher-D) between them.
  3. Among many options, it picks the one with the largest margin.
  4. Points closest to the boundary are support vectors — they define the fence.
  5. New points are classified by which side of the boundary they fall on.

Picture it

Margin = street width between two neighborhoods.

Hyperplane = the painted center line.

Support vectors = the houses right on the curb — they set the street width.

Wider street → usually more confident separation (when data allows it).

Key takeaways

  • SVM maximizes margin, not just “draws any line that works.”
  • Only support vectors really matter for the final boundary.
  • Nonlinear data? Use a kernel (e.g. RBF) instead of forcing a straight line in the original features.

Where it’s used

Text classification · image categories · bioinformatics · fraud / anomaly flags · medical risk scores — anywhere you need a sharp boundary with limited, well-labeled data.
