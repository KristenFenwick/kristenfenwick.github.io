SVM · mathematical sketch

just enough formality to read a paper or sklearn docs

1. Linearly separable case

Data (xi, yi) with labels yi ∈ {−1, +1}. Hyperplane: wᵀx + b = 0.

Constraints (points on the correct side with margin):

yi (wᵀxi + b) ≥ 1 for all i

Margin width is proportional to 2 / ||w||. So we minimize ||w|| (equivalently ½||w||²) subject to those constraints.

2. Soft margin (overlap allowed)

Real data overlaps. Introduce slack ξi ≥ 0 and a tradeoff C:

min ½||w||² + C Σ ξi
s.t. yi(wᵀxi + b) ≥ 1 − ξi

C large → fewer mistakes, tighter fit (risk: overfit).
C small → wider margin, more mistakes allowed.

3. Kernel trick

Map x → φ(x) in a higher-dimensional space without building φ explicitly. Work with kernel K(x, x′) = ⟨φ(x), φ(x′)⟩.

Common kernels:

  • Linear: K = xᵀx′
  • Polynomial: K = (xᵀx′ + c)d
  • RBF (Gaussian): K = exp(−γ ||x − x′||²)

4. Decision

f(x) = sign( Σ αi yi K(xi, x) + b )

Only points with αi > 0 are support vectors. Everyone else is along for the ride.

Lab checklist

  • Scale features (StandardScaler) before RBF / linear SVM — distances matter.
  • If accuracy is 1.00 on a huge “easy” dataset, check leakage & class balance before celebrating.
  • Report precision / recall / F1, not only accuracy.
